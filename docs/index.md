# install

Automated, single-file setup scripts for macOS, Fedora, Ubuntu, Omarchy and Windows PowerShell, plus the shared shell, editor, tmux and herdr configuration they deploy. This knowledge base holds the reasoning and guides that the scripts themselves cannot express.
